GitHub & Render Canlıya Alma Rehberi

Bu projeyi kendi GitHub deponuza aktarıp Render.com üzerinde ücretsiz bir şekilde yayına alabilirsiniz.

1

Yerel Test & Kurulum

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

Tarayıcınızda http://localhost:5000 adresinden test edebilirsiniz.

2

GitHub'a Yükleme

git init
git add .
git commit -m "feat: Türkçe Duygu Analizi Flask"
git remote add origin <repo-url>
git push -u origin main

Hazırlanan .gitignore ve Procfile dosyaları hazırdır.

3

Render.com Dağıtımı

Environment: Python 3

Build Command: pip install -r requirements.txt

Start Command: gunicorn app:app --timeout 120

Render.yaml dosyası dahil edildiğinden tek tıkla otomatik oluşturulabilir.
